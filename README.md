# Chris Jose: Portfolio

A scroll-driven portfolio built as a train ride. Scroll, and a train pulls in from deep space. Every stop is a chapter of the site.

**Live site:** https://chris-jose-portfolio.vercel.app/

## What's inside

- A split-flap departure board and a train that arrives from warp speed
- A carriage window, a dot field, a workflow that lights up as you scroll, and a graph you can scrub
- A 3D device that comes apart piece by piece, then turns into the train and rolls away
- A train of carriages you ride through, and boarding passes at the end

## Built with

- React, Vite and TypeScript
- Three.js with react-three-fiber (only for the 3D device)
- Lenis for smooth scrolling
- Hand-built canvas and SVG scenes

## Run it locally

    npm install
    npm run dev

Open the address it prints. Add `?static` to the end of the address to see the site without animation.
